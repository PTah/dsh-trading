# Agent Note: 图表可见窗口增加 2–12 个日历月

Status: implemented

## Problem

周期胶囊是 K 线粒度（1 分、日 K、周 K、月 K）。用户要的是把图缩到最近 2、3、4、5、6 或 12 个日历月，这两种控制不是同一件事。

## Decision

行情工具栏在周期胶囊右侧加一组窗口按钮：`2 мес` … `12 мес`。点中后 `TvChart` 用 `setVisibleLogicalRange` 把最后一根 bar 往前数 N 个日历月的区间铺开。再点一次同一按钮，或改点任意周期，窗口取消，视窗回到该周期的默认右缘。分钟线和五日视图装不下这么长的历史，点窗口时改到日 K。序列比窗口短时画出全部已有 bar。窗口不改变取数条数。

## Alternatives considered

把 2/3/4/5/6/12 个月做成新的 K 线周期。上游没有这种粒度，月 K 已经是 `1M`，再造周期会和「看最近几个月」的需求错位。

只把日 K 的默认缩放改成固定六个月。用户要的是能切换的一组窗口，不是换一个默认值。

## Consequences

日 K 仍然一次取 750 根，12 个月落在这段里面。更长的历史不在这组按钮里。用户缩放或平移之后，同一次窗口选择不会被行情轮询抢走；换标的或换周期会按当前窗口重算。
