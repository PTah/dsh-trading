# 俄股（MOEX）交易风控检查清单（ru-risk-checklist）

开仓前逐项核对；任何一项不通过即不入场，并将未通过项写入交易计划的风险栏。
数据来源约定：行情与账户信息以 T-Bank Invest 连接器（tradingRuMarketData / tradingRuTrade）返回为准；
莫斯科交易所（MOEX）品种目录、整手数、交易时段以连接器实际返回为权威，本清单不构成投资建议。

**依据闸门（先过）**：每条开仓理由必须能指回锚点（工具名 + 参数 + 数值 + 数据时间 / 公告或章节 / facts 条目 / 知识卡 id + updatedAt）。只有 C/D/E 级来源、或写不出锚点的理由，按证据不足处理（insufficient），不得作为入场依据。

## 1. 结算与交收（T+1）

- [ ] MOEX 股票/ETF 交收周期为 T+1（成交后下一交易日交收）；卖出后资金/份额 T+1 可用，当日回转注意资金占用。
- [ ] T+1 交收不等于可无限日内回转：核对账户/经纪商（T-Bank）对日内交易次数与保证金要求的额外限制。
- [ ] 跨周末/节假日的 T+1 交收会推迟到下一交易日，注意资金到账时间与再投资节奏错配。

## 2. 整手（Lot Size）

- [ ] MOEX 股票按"手"（lot）交易，每个品种整手股数不同（如 1/10/100 股一手）；下单前核对品种目录 `lot` 字段，数量必须是整手的整数倍。
- [ ] 零股（odd lot）在主板撮合中流动性显著更差，必要时走场外协商或接受更大滑点。
- [ ] 仓位规模计算（名义价值、风险百分比）必须按"手数 × 每手股数 × 价格"展开，不得直接用股数估算。

## 3. 货币计价与汇率（RUB）

- [ ] MOEX 多数蓝筹以卢布（RUB）计价，部分品种存在双计价或跨境结算安排；下单前明确当前计价货币，不得与美元/人民币计价品种混淆。
- [ ] 持有 RUB 计价资产的非卢布本位账户，汇率波动是独立于股价的额外风险源：换算本币盈亏时必须同时核对入场与当前的 RUB 汇率，不得只看股价涨跌。
- [ ] 卢布汇率受地缘政治、制裁消息、油价与央行利率决议影响剧烈，波动幅度可能超过标的股价当日波动，仓位规模需纳入汇率联动风险；资本管制政策可能影响资金出入境与兑换时效。

## 4. 交易时段与休市跳空

- [ ] MOEX 主板常规交易时段（莫斯科时间）与节假日日历以连接器返回的当前时段为准，不得按记忆硬编码；开盘集合竞价阶段报价波动大，避免在集合竞价阶段市价扫单。
- [ ] 周末（周六、周日）与俄罗斯法定节假日休市：隔夜/跨周末持仓的跳空风险按 2-3 个交易日的累积消息面变化压力测试，而非按单日跳空估算。
- [ ] 地缘政治、制裁消息、央行声明常在非交易时段发布：休市期间的消息面积累是下一交易日开盘跳空的主要来源，持仓过节前重新评估仓位。

## 5. IIS 账户（个人投资账户）规则

- [ ] IIS（Индивидуальный инвестиционный счёт / 个人投资账户）享受税收优惠，但有锁定期（通常 3 年起）与年度注资上限；提前销户会追溯取消已享受的税收优惠。
- [ ] IIS 账户与普通经纪账户的资金/标的不能直接互转，下单前确认操作的是哪个账户，避免误用 IIS 额度或触发提前销户的税务后果。
- [ ] IIS 账户的提现限制比普通账户更严格：计划资金用途时，不要把 IIS 内资产当作可随时赎回的流动性。

## 6. Sandbox 与 Live Token 区分

- [ ] T-Bank Invest API 的 sandbox（模拟）环境与生产（真实资金）环境使用不同的 token/凭证，sandbox 的行情与成交为模拟数据，不代表真实市场深度或真实成交质量。
- [ ] 本连接器默认 `env=demo`（sandbox）+ `dryRun=true`：任何从 sandbox 切到生产 token、或将 dryRun 关闭为真实下单的操作，必须经过显式人工确认与 liveTrading 开关（铁律 #3 统一闸门），不得因切换 token 文件而误以为仍是模拟盘。
- [ ] sandbox 环境的账户余额、持仓、委托簿是独立模拟状态，不与生产账户同步；核对工具返回的 `env` 字段，避免把 sandbox 回执误读为真实成交确认。

## 7. 清单归属（谁管哪一类）

- 本清单只管**俄罗斯 MOEX 股票/ETF**（`ru` 市场，T-Bank Invest 连接器数据面 + 交易面）。
- 海外上市的俄罗斯存托凭证（ADR/GDR）、因制裁被摘牌或限制交易的俄罗斯关联标的不在本清单覆盖范围，其流动性与可交易性需单独核实，不得套用本清单的时段/结算假设。
- 美股/港股/A股相关风控分别走 `us-risk-checklist` / `hk-risk-checklist` / `cn-risk-checklist`；不互相映射。

## 8. 品种与数据面核对（连接器能力边界）

- [ ] 行情与交易数据以 T-Bank Invest 连接器实际返回为准；连接器处于模板/占位阶段或 sandbox 限流时，核对返回字段是否完整，不得用占位值冒充真实报价。
- [ ] 制裁与合规环境可能导致特定标的或功能（如某些跨境资金通道）临时不可用：遇到持续性的接口错误或合规拒绝，优先怀疑合规/制裁限制而非连接器故障，并如实告知用户。
- [ ] 真实下单（dryRun=false）需显式 liveTrading 授权与账户侧人工确认；agent 输出仅作计划与提醒，不构成投资建议。
